# 🎮 Hangman Game

## 📌 Project Overview
Hangman Game is a Python console-based game where the player guesses a hidden word one letter at a time. The game includes multiple categories, difficulty levels, hints, score tracking, and replay functionality.

## ✨ Features
- Multiple Word Categories
- Difficulty Levels (Easy, Medium, Hard)
- Word Hints
- Wrong Letter Tracking
- Remaining Attempts Display
- Score Board
- Win Percentage Calculation
- Play Again Option
- Input Validation

## 🛠️ Technologies Used
- Python 3
- Random Module

1. Install Python 3.
2. Open the project folder in VS Code.

4. Run:

```bash

```
